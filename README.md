# AutoOrder Engine - Smart E-Commerce & Facebook Order Automation System

একটি আধুনিক, স্বয়ংক্রিয় বিজনেস অর্ডার প্রসেসিং ও ইনভয়েস অটোমেশন সিস্টেম। ফেসবুক মেসেঞ্জার, লিড বিজ্ঞাপন বা ড্রপ ফোল্ডারে নতুন কোনো অর্ডার আসা মাত্র কোনো মানুষের সাহায্য ছাড়াই এটি স্বয়ংক্রিয়ভাবে মেমো (PDF Invoice), নোটিফিকেশন এবং সেলস হিসাব তৈরি করে ফেলে।

---

## প্রজেক্টের বৈশিষ্ট্যসমূহ (Key Features)

1. **Meta Facebook Webhook Integration:**
   - অফিসিয়াল ফেসবুক ডেভেলপার পোর্টালের সাথে সরাসরি কানেক্ট করার জন্য Webhook ভেরিফিকেশন ও মেসেজ রিসিভার।
2. **স্বয়ংক্রিয় PDF ইনভয়েস জেনারেটর (QR Code সহ):**
   - প্রতিটা অর্ডারের জন্য নিখুঁত হিসাবসহ প্রফেশনাল ভেক্টর PDF ইনভয়েস তৈরি হয়।
3. **কাস্টমার নোটিফিকেশন প্রস্তুতকারক:**
   - কাস্টমারের জন্য বাংলা/ইংরেজিতে WhatsApp ও SMS কনফার্মেশন বার্তা প্রস্তুত করে।
4. **ফাইল ওয়াচার অটোমেশন (Folder Watcher):**
   - `data/incoming/` ফোল্ডারে কোনো অর্ডার ফাইল ড্রপ হওয়া মাত্র স্বয়ংক্রিয়ভাবে প্রসেস হয়ে আর্কাইভে চলে যায়।
5. **লাইভ মনিটর ও ভিজ্যুয়াল কনসোল (Live Dashboard):**
   - স্যার বা ক্লায়েন্টকে লাইভ ডেমো দেখানোর জন্য রিয়েল-টাইম ৫-ধাপের পাইপলাইন ভিউয়ার এবং ১-ক্লিক ট্রিগার বাটন।
6. **সেলস লেজার সিনক্রোনাইজেশন:**
   - স্বয়ংক্রিয়ভাবে `sales_ledger.csv` এবং `sales_ledger.json` আপডেট রাখে যা এক্সেলে সরাসরি ওপেন করা যায়।

## কীভাবে চালাবেন (How to Run)

১. টার্মিনাল ওপেন করে প্রজেক্ট ফোল্ডারে যান:
```bash
cd C:\Users\assdi\.gemini\antigravity\scratch\ecommerce-order-automation
```

২. সার্ভার চালু করুন:
```bash
npm start
```

৩. যেকোনো ব্রাউজারে নিচের লিংকে প্রবেশ করুন:
```
http://localhost:3000
```

## ফাইল ও ফোল্ডার ডিরেক্টরি পরিচিতি

* `src/pipeline.js` - মূল অটোমেশন পাইপলাইন এবং বিজনেস লজিক।
* `src/invoiceGenerator.js` - PDFKit ও QRCode দিয়ে ইনভয়েস তৈরির ইঞ্জিন।
* `src/facebookWebhook.js` - ফেসবুক ওয়েববুক এবং মেসেজ পার্সার।
* `src/watcher.js` - স্বয়ংক্রিয় ফোল্ডার মনিটরিং ইঞ্জিন।
* `src/server.js` - এক্সপ্রেস সার্ভার ও লাইভ SSE ব্রডকাস্টার।
* `public/` - লাইভ অটোমেশন কন্ট্রোল ড্যাশবোর্ড (HTML/CSS/JS)।
* `output/invoices/` - স্বয়ংক্রিয়ভাবে তৈরি হওয়া সব PDF ইনভয়েস।
* `output/notifications/` - কাস্টমারদের জন্য রেডি হওয়া মেসেজসমূহ।
* `output/sales_ledger.csv` - এক্সেল ফরম্যাটে সেলস রেকর্ড।
* `PRESENTATION_SCRIPT.md` - স্যারকে প্রেজেন্টেশন দেওয়ার সম্পূর্ণ গাইড।
